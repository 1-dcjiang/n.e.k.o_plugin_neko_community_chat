# 喵宇宙社区聊天（neko_community_chat）

把喵宇宙社区（community.project-neko.cn）和本地 YUI 连起来的聊天插件：本地跑一个消息服务，
提供一个和 QQ 差不多的聊天面板，和 YUI 实时对话；打开喵宇宙社区网页时右下角会出现聊天窗。

## 使用前提

1. 本插件已安装并启用（`plugin_runtime.auto_start = true`，启动即拉起本地服务 127.0.0.1:7870）
2. YUI 正常在线（插件通过 YUI 的推送通道唤醒她回复）

## 两种打开方式

| 方式 | 位置 | 说明 |
|---|---|---|
| 本地聊天页 | 浏览器打开 `http://127.0.0.1:7870/chat`（或 N.E.K.O 客户端「喵宇宙聊天」面板） | 完整 QQ 式界面：左侧会话栏、气泡聊天、输入框，右侧切换「社区动态」看动态流 |
| 社区网页注入 | 打开 `community.project-neko.cn`，右下角出现猫娘按钮 🐱 | 点击展开聊天窗（本地面板嵌入），可拖拽、可关闭 |

## 和 YUI 聊天的流程（自动）

1. 你在面板输入消息 → 本地服务记录并存 inbox
2. 插件后台（每 5 秒）发现新消息 → 通过推送通道唤醒 YUI，告诉她"用户在聊天面板对你说：…"
3. YUI 用 `community_chat_send` 把回复写回本地 → 面板轮询（每 3 秒）自动显示
4. 历史记录存在 `%LOCALAPPDATA%/N.E.K.O/neko_community_chat/messages.jsonl`（本地，不联网）

## 社区动态

- 面板右侧「社区动态」标签实时拉取官方动态流 `/api/feed`（真实接口）
- 社区官方**目前没有消息/聊天 API**，所以"和其他用户聊"暂不可用；
  架构已预留——官方开放消息接口后直接对接，无需改面板

## 油猴脚本安装（社区网页聊天窗）

1. 浏览器装 Tampermonkey（篡改猴）
2. 打开 `userscript/neko_chat.user.js` 复制全文，新建脚本粘贴保存（或直接把文件拖进 Tampermonkey）
3. 打开 `community.project-neko.cn` → 右下角出现 🐱 按钮 → 点击展开聊天窗
4. 注意：聊天窗连的是本地服务，**插件未运行时窗口会显示"本地服务不可达"**

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 面板提示"本地服务不可达" | 插件未启动 / 7870 端口被占 | 确认插件已启用；若端口被占，用 `NEKO_COMMUNITY_CHAT_PORT` 改端口并同步改面板 |
| YUI 不回消息 | 唤醒推送失败或 YUI 忙碌 | 稍等再发一条；或用 `community_chat_status` 查看服务状态 |
| 社区动态空 | 官方 feed 暂无内容或网络受限 | 面板会显示"社区暂无动态"或错误原因，如实为准 |

## 工具（YUI 侧）

- `community_chat_send`：YUI 把回复发回聊天面板
- `community_chat_read`：YUI 读最近聊天记录
- `community_chat_status`：服务状态（在线/消息数/feed 地址）
