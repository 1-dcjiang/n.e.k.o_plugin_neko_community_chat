# 喵宇宙社区聊天（neko_community_chat）

把喵宇宙社区（community.project-neko.cn）和本地 YUI 连起来的聊天插件：本地跑一个消息服务，
提供一个和 QQ 差不多的聊天面板，和 YUI 实时对话；打开喵宇宙社区网页时右下角会出现聊天窗。

v0.2 起支持**多节点互联**：同一局域网自动互相发现直接互通；配置公网中继后，
全球所有装了本插件的节点都能互相聊天、互发社区动态（自建社区墙）。

## 使用前提

1. 本插件已安装并启用（`plugin_runtime.auto_start = true`，启动即拉起本地服务 127.0.0.1:7870）
2. YUI 正常在线（插件通过 YUI 的推送通道唤醒她回复）

## 两种打开方式

| 方式 | 位置 | 说明 |
|---|---|---|
| 本地聊天页 | 浏览器打开 `http://127.0.0.1:7870/chat`（或 N.E.K.O 客户端「喵宇宙聊天」面板） | 完整 QQ 式界面：左侧三个页签（和 YUI 聊天 / 社区动态 / 节点与设置） |
| 社区网页注入 | 打开 `community.project-neko.cn`，右下角出现猫娘按钮 🐱 | 点击展开聊天窗（本地面板嵌入），可拖拽、可关闭 |

## 和 YUI 聊天的流程（自动）

1. 你在面板输入消息 → 本地服务记录并存 inbox（并广播给所有在线节点）
2. 插件后台（每 5 秒）发现新消息 → 通过推送通道唤醒 YUI，告诉她"用户在聊天面板对你说：…"
3. YUI 用 `community_chat_send` 把回复写回本地 → 面板轮询（每 3 秒）自动显示
4. 历史记录存在 `%LOCALAPPDATA%/N.E.K.O/neko_community_chat/messages.jsonl`（本地，不联网）

## 多节点互联（v0.2）

**机制**：每台装了插件的电脑都是一个节点。节点通过 UDP 广播（7872）在局域网内互相发现，
互推走专用局域网口 7871（只接受互推消息，不暴露聊天历史）；消息带 peer_id/peer_name/来源标签
（局域网/公网），面板气泡上会显示"谁发来的、走哪条通道"。

- **局域网互通（零配置）**：同一 WiFi/路由器的多台电脑装上插件后自动互相可见。
  打开面板「节点与设置」可看到在线节点，点某节点「回复」即可把消息定向发给他
  （不唤醒本机 YUI，直接送达对方面板）；发消息默认广播给所有节点。
- **公网互通（需要中继）**：把 `relay/worker.js` 部署到 Cloudflare Workers
  （需要 Durable Object，命名空间 `RELAY`，可按需设 RELAY_TOKEN），
  然后把中继 URL 填到面板「节点与设置 → 中继 URL」并保存。
  节点会每 3 秒轮询中继收发消息，全球节点即可互通。
- **自建社区墙**：面板「社区动态」页签顶部有发布框，发帖广播给所有节点
  （帖子带来源标签：局域网/公网/官方社区只读流）。

## 社区动态

- 面板「社区动态」页签 = **自建墙**（所有节点发帖，互发）+ **官方社区只读流**
  （官方 `/api/feed` 真实接口，官方发帖需登录，暂只读）
- 官方社区目前**没有消息/聊天 API**，所以"和其他用户聊"由自建墙+节点互联替代

## 油猴脚本安装（社区网页聊天窗）

1. 浏览器装 Tampermonkey（篡改猴）
2. 打开 `userscript/neko_chat.user.js` 复制全文，新建脚本粘贴保存（或直接把文件拖进 Tampermonkey）
3. 打开 `community.project-neko.cn` → 右下角出现 🐱 按钮 → 点击展开聊天窗
4. 注意：聊天窗连的是本地服务，**插件未运行时窗口会显示"本地服务不可达"**

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 面板提示"本地服务不可达" | 插件未启动 / 7870 端口被占 | 确认插件已启用；若端口被占，用 `NEKO_COMMUNITY_CHAT_PORT` 改端口并同步改面板 |
| YUI 不回消息 | 唤醒推送失败或 YUI 忙碌 | 稍等再发一条；或用 `community_chat_status` 查看服务状态 |
| 社区动态空 | 官方 feed 暂无内容或网络受限 | 面板会显示"社区暂无动态"或错误原因，如实为准 |
| 节点列表看不到其他电脑 | 不在同一局域网，或对方未开插件 | 同一 WiFi 自动发现；跨网络需配置公网中继 URL |
| 面板页签点了没反应 | 面板脚本被浏览器缓存了旧版 | 强制刷新（Ctrl+F5）或重启 N.E.K.O 客户端 |

## 工具（YUI 侧）

- `community_chat_send`：YUI 把回复发回聊天面板（远端消息可带 `target_peer` 定向回复对方）
- `community_chat_read`：YUI 读最近聊天记录
- `community_chat_status`：服务状态（在线/消息数/feed 地址）
